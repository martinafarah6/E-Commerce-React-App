# E-Commerce Store

A responsive online store built with React 19 and React Router.

**Live Demo:** https://martinafarah6.github.io/E-Commerce-React-App/

## Features

- Product listing
- Favorites page
- Shopping cart page
- Authentication pages
- User dashboard
- Cart and favorites stay saved after a page refresh

## Tech Stack

- React 19 (Create React App)
- React Router (react-router-dom)
- JavaScript, CSS
- Deployed on GitHub Pages

## Run Locally

```bash
git clone https://github.com/martinafarah6/E-Commerce-React-App.git
cd E-Commerce-React-App
npm install
npm start
```

The app opens at http://localhost:3000.
